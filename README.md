# 📕 JM 漫画下载助手（JMComic Downloader）

独立的 **Android APP**，可下载禁漫天堂（JMComic）全站漫画，支持按漫画码下载、搜索、排行榜和**随机下载**。下载完成后自动 AES-256 加密打包（本 APP 与任何 QQ 机器人/插件无关，完全独立使用）。

---

## 🎲 v1.3 新功能：随机下载

不用找资源，直接随机来一本！

### 指令（聊天框输入）
| 指令 | 功能 |
|------|------|
| `random` / `随` / `随机` / `rp` | 🆕 全站随机挑一本 → 显示信息 → 自动下载 |
| `dl 漫画码` | 下载指定漫画（如 `dl 515320`） |
| `dl 漫画码 并发数` | 指定并发下载（如 `dl 515320 10`） |
| `漫画码`（纯数字） | 查询漫画信息 |
| `diag` | 网络诊断 |
| `help` | 查看帮助 |

### 随机下载流程
1. 🎲 从全站列表随机翻页（1~200 页）挑一本
2. 📖 显示标题、作者、页数
3. ⬇️ 自动开始下载（并发 5）
4. 📂 保存到「文档/JM漫画/漫画码/」

## 🛠️ 技术说明
- 双引擎：jmcomic（Python）+ jm_node（Node.js）
- 图片 CDN 域名轮换自动适配（每次实时获取最新签名 URL）
- 切片图片自动还原（MD5 分片算法）
