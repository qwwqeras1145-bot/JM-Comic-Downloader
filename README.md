# 📕 JM 漫画下载助手（JMComic Downloader）

全站漫画下载工具：**Android APP** + **QQ 机器人插件（AstrBot）** 双形态，双引擎（jmcomic Python + jm_node Node.js），下载自动 AES-256 加密打包。

---

## 🎲 v1.3 新功能：随机下载

不用找资源，直接随机来一本！支持两种形态：

| 形态 | 指令 | 说明 |
|------|------|------|
| 📱 Android APP | `random` / `随` / `随机` / `rp` | 全站随机挑一本 → 显示信息 → 自动下载 |
| 🤖 QQ 机器人 | `/jm random` | 同上，下载完自动加密发压缩包+密码 |

---

## 📱 Android APP

### 指令（聊天框输入）
| 指令 | 功能 |
|------|------|
| `random` / `随` / `随机` / `rp` | 🆕 随机下载一本漫画 |
| `dl 漫画码` | 下载指定漫画（如 `dl 515320`） |
| `dl 漫画码 并发数` | 指定并发下载（如 `dl 515320 10`） |
| `漫画码`（纯数字） | 查询漫画信息 |
| `diag` | 网络诊断 |
| `help` | 查看帮助 |

### 下载
- 最新版 APK 见右侧 **Releases**（v1.3，保留 v1.2 历史版本）

## 🤖 QQ 机器人插件（AstrBot）

插件位于 `qq-plugin/` 目录（jm_downloader v2.1.0），适配 AstrBot 4.x。

### 安装
1. 将 `jm_downloader/` 文件夹放入 `AstrBot/data/plugins/`
2. 重启 AstrBot
3. 需要 Node.js 运行时：将插件自带 `nodejs/`（或任意 Node 18+）放入 `jm_downloader/nodejs/`

### 指令（群聊直接发，无需唤醒词）
| 指令 | 功能 |
|------|------|
| `/jm random` | 🆕 全站随机挑一本并自动下载（自动加密） |
| `/jm 漫画码` | 查询信息 |
| `/jm dl 漫画码 [并发]` | 下载（node 引擎，默认并发5） |
| `/jm dlj 漫画码 [并发]` | 下载（jmcomic 引擎，默认并发3） |
| `/jm search 关键词 [页码]` | 搜索 |
| `/jm top [日榜/周榜/月榜] [页码]` | 排行榜 |
| `/jm version` | 版本信息 |

### 特性
- 🔒 下载完成自动 AES-256 加密打包，发压缩包 + 随机解压密码
- 🐍 + 🟢 双引擎互备降级（查询/搜索/下载失败自动切换）
- 🎲 随机下载：官方 search 空关键词接口 + AES 解密 + 随机翻页（1~200页）
